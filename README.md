Участие в коммерческих проектах:
Развертывание и поддержка высокодоступного сервиса Telegram-ботов
Спроектировал и развернул мультиконтейнерную среду для Telegram-ботов (Python) с использованием Docker Compose: организовал связку «бот + Redis (кэш) + PostgreSQL (хранилище)» с изолированными сетями и управлением конфиденциальными данными через .env.
Настроил ротацию логов и централизованное логирование для быстрой отладки инцидентов.
Реализовал мониторинг доступности и производительности ботов с помощью Zabbix: настроил сбор метрик (количество обработанных сообщений, ошибки, задержки ответа), создал дашборды и триггеры для алертинга с отправкой уведомлений в Telegram при падении сервиса или превышении порогов.
Автоматизировал обновление ботов через CI/CD: настроил Git webhook, который запускает сборку нового образа и выполняет передеплой с минимальным даунтаймом.
Обеспечил горизонтальное масштабирование: добавил поддержку нескольких экземпляров бота с балансировкой через Nginx, что позволило выдерживать пиковые нагрузки без потери производительности.

Развертывание распределённой VPN-инфраструктуры на базе Xray
Спроектировал и развернул многосерверную VPN-сеть с использованием протокола Xray (VLESS, VMess) на нескольких VPS в разных географических регионах для обеспечения низкой задержки и отказоустойчивости.
Настроил различные транспорты: TCP, UDP, HTTP, XHTTP, gRPC
Внедрил панель управления Remnawave для централизованного создания и управления пользователями, мониторинга их подключений, статистики трафика и выставления лимитов.
Организовал единую точку входа через reverse-proxy на базе Nginx: настроил балансировку между серверами, терминацию TLS (сертификаты Let's Encrypt, автоматическое обновление), проксирование WebSocket и gRPC.
Развернул систему мониторинга всех VPN-нод: сбор метрик загрузки CPU/RAM, сетевого трафика, количества активных соединений с отправкой алертов в Telegram при падении ноды или превышении нагрузки.
